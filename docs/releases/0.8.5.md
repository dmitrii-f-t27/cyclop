Форк-выпуск: языковой пакет скачивается из самой панели — без зависания и без повторного ввода текста.

**Download живёт в панели, а не только в настройках.** macOS не отдаёт
языковой пакет без подтверждения пользователя. Раньше это выглядело как
зависание: `prepareTranslation()` ждал системное окно, которое над
неактивируемой панелью-чёлкой появиться не могло. Теперь панель заранее
проверяет статус пары, и если пакета нет — рядом с ошибкой появляется кнопка
**Download**: она открывает обычное окно, где macOS показывает своё
подтверждение. После подтверждения пакет скачивается, и панель сама повторяет
перевод — текст заново вводить не нужно. Кнопка «Translation Languages…»
и путь через System Settings → General → Language & Region остаются
запасными.

Проверено владельцем на установленной паре pt-BR ↔ ru: «Olá, tudo bem?» →
«Привет, как дела?»; перевод с русского — после выбора языка в заголовке
колонки. Пакеты en/de/th Apple не предустанавливает: de/th нужно один раз
подтвердить при первом переводе.
