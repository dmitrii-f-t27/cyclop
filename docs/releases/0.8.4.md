Форк-выпуск: в «Переводе» пару с русским можно выбрать — не только английский.

**Язык пары выбирается в заголовке колонки.** В апстриме перевод был жёстко
английский ↔ русский, направление выбиралось по письменности текста. Теперь
не-русскую сторону можно выбрать: EN English, DE Deutsch, PT Português
(Brasil), TH ไทย. Направление по-прежнему читается по письменности: латиница
и тайский идут в русский, кириллица — в выбранный язык, поэтому одно нажатие
даёт оба направления. Выбор сохраняется в `config.json` и переживает
перезапуск; английский остаётся языком по умолчанию, так что старый сценарий
не меняется. Сделано в форке Дмитрием Федоровым
([@dmitrii-f-t27](https://github.com/dmitrii-f-t27)) на основе
[Cyclop](https://github.com/akalikbergenov/cyclop) 0.8.3 (MIT).

Языковые пакеты de/th Apple не предустанавливает: при первом переводе их нужно
один раз скачать — System Settings → General → Language & Region →
Translation Languages…

Подпись ad-hoc, без Developer ID и нотаризации: на другой машине первый запуск
может попросить System Settings → Privacy & Security → Open Anyway.
