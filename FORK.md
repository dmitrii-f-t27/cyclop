# Форк Cyclop

Этот репозиторий — публичный форк [akalikbergenov/cyclop](https://github.com/akalikbergenov/cyclop)
(MIT). Всё, что было в 0.8.3, работает как раньше; ниже — единственное отличие.

## Что добавлено: выбор языка во вкладке Translate

В апстриме перевод был жёстко английский ↔ русский, а направление выбиралось по
письменности текста. Теперь не русскую сторону пары можно выбрать:

| Код | Язык |
|---|---|
| EN | English |
| DE | Deutsch |
| PT | Português (Brasil) |
| TH | ไทย |

- Выбранный язык стоит в заголовке своей колонки; нажатие на заголовок
  открывает список языков (тот же приём, что у выбора валюты).
- Направление по-прежнему определяется письменностью: латиница и тайский идут
  **в русский**, кириллица идёт **в выбранный язык**. То есть одно нажатие даёт
  оба направления — German → Russian и Russian → German, и так же для PT-BR и TH.
- Выбор сохраняется в `~/Library/Application Support/Cyclop/config.json`
  (`translateLanguage`) и переживает перезапуск.
- Английский остаётся языком по умолчанию, так что старый сценарий не меняется.

Скриншот вкладки до изменения — [`docs/translate-pane.png`](docs/translate-pane.png).

### Языковые пакеты

Apple не предустанавливает языки перевода. Когда пакета нет, в панели рядом с
«Translation Languages…» появляется **Download**: он открывает обычное окно, в
котором macOS показывает своё подтверждение загрузки. Панель-notch такое окно
показать не может — она неактивируемая и без рамки, — поэтому загрузка вынесена
в отдельное окно.

После подтверждения пакет скачивается один раз, и панель сама повторяет перевод.
Альтернативный путь — **System Settings → General → Language & Region →
Translation Languages…**.

## Сборка и установка

```bash
git clone git@github.com:dmitrii-f-t27/cyclop.git
cd cyclop
./Scripts/bundle.sh          # swift build + .app + ad-hoc подпись
open build/Cyclop.app
```

Требования те же, что у апстрима: macOS 15+ и Swift 6 (полный Xcode не нужен,
Command Line Tools достаточно). Версия форка — **0.8.5**.

`Cyclop-0.8.5.zip` лежит в релизах этого репозитория; приложение там
подписано ad-hoc, поэтому на другой машине первый запуск может попросить
**System Settings → Privacy & Security → Open Anyway**.
